mioctl TUI 布局方案

哪种整体布局最适合这个 mihomo 管理工具？考虑使用场景：快速查看状态、切换节点、排查连接问题。

A

Tab 切换布局

顶部固定 Tab 栏，下方为内容区。类似 htop/btm 风格。最经典的 TUI 导航模式，键盘操作直觉（← → 切 Tab）。

B

侧边栏 + 主区域

左侧固定导航栏，右侧为主内容区域。类似 lazygit 风格。可同时看到导航和内容，切换视图无需离开当前位置上下文。

C

单页仪表盘

所有信息在一个可滚动页面中，按区块排列（概览 → 节点 → 连接 → 日志）。一屏看全貌，但内容多时需要滚动。
